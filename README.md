# Michealla Beltran — Portfolio

Portfolio of Michealla Beltran, a 21-year-old BSCS 3B student and web developer from Guiling, Candijay, Bohol. Projects, skills, numbers and testimonials are mock content for a class project; the email and Facebook link are real.

**Stack:** React 18 · Vite · plain CSS · three.js · @react-three/fiber · @react-three/rapier · meshline (the draggable 3D lanyard card)

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # static site in ./dist
```

Content lives in `src/data.js`; her photo is `public/michealla.jpg`. Pushing to `main` deploys to GitHub Pages through `.github/workflows/deploy.yml` (set **Settings → Pages → Source** to **GitHub Actions**).
